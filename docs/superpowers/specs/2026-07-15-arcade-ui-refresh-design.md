# 世界杯点球大战 3D：街机 UI 与赛场任务改版设计

## 目标

在不重写现有 Three.js 点球核心的前提下，把页面从“功能完整的网页小游戏”提升为有统一美术语言、清晰操作层级和赛事仪式感的桌面优先游戏。视觉采用高对比街机贴纸风，保留糖豆人角色的轻松气质；玩法只增加一层轻量赛场任务，避免破坏已有随机性和杯赛平衡。

## 视觉方向

- 主色使用午夜蓝、世界杯金、草坪绿和进球珊瑚红，减少目前多个互不关联的渐变与边框样式。
- 组件统一采用粗描边、偏移硬阴影、切角标签和小幅旋转，形成足球贴纸与街机选人界面的质感。
- 保留 `Baloo 2` 作为圆润标题字，补充系统无衬线字体处理小字和数字，提高 HUD 可读性。
- 所有核心交互目标不小于 44px，提供明显 hover、focus-visible、active 状态，并支持 `prefers-reduced-motion`。

## 页面设计

### 首页

首页改为左右分栏的赛事海报：左侧包含届次标签、主标题、简短玩法说明、开始按钮、语言与声音控制；右侧用 CSS 生成球场聚光灯、足球轨迹、奖杯和赛制卡片。底部用三张紧凑能力卡说明“弧线、读门将、捧杯”主循环。

### 选队页

桌面端采用三栏英雄选人布局：

1. 左侧球队导航显示 8 支球队的国旗、国家名和队长号码，可点击或使用方向键切换。
2. 中间是当前球队的超大视觉舞台，显示国旗水印、现有 CSS 糖豆人、队名、球星和球队色。
3. 右侧展示力量、精准、队长特长、五人罚球队列与确认按钮。

移动端降级为顶部横向球队导航、中间英雄卡和底部属性面板，允许纵向滚动。选择改变时只更新 DOM 内容，不重建游戏数据。

### 比赛 HUD

- 顶部整合阶段、比分、风力和声音，使用统一的半透明深色面板与黄色比赛标签。
- 左侧连击与赛场任务组成状态卡；完成任务时使用短促的贴纸弹出动画。
- 底部操作提示、球员标签、弧线和力度控件共享相同圆角、描边与阴影规范。
- 关键结果文字保留夸张感，但减少与 HUD 争抢层级的常驻装饰。

## 轻量玩法：赛场任务

每场比赛开始时从以下任务中选择一个，整场只出现一次：

- 连进 2 球。
- 用弧线球得分。
- 完成 1 次扑救。
- 用队长取得进球。

任务只记录成就，不改变射门概率和比赛胜负。完成时播放视觉反馈，并在结算统计中显示本届杯赛完成任务数。这样能提供每场不同的小目标，又不会让玩家因随机任务失去比赛。

## 状态与数据流

- 在现有 `G` 状态中增加当前任务、任务进度、是否完成和累计完成数。
- 开赛/晋级时生成任务；射门结算和扑救结算后通过一个独立函数更新进度。
- UI 渲染函数只读取状态并更新文本、进度与完成样式，避免把任务判断散落在点击处理器中。
- 多语言文本继续沿用现有 `UI`、`TF` 和 `LI()` 机制。

## 错误处理与兼容

- Three.js 或球门模型加载失败时不改变现有行为；UI 仍可显示。
- 不引入新的网络请求、依赖或构建工具。
- 保持 Chrome、Safari、移动触控与现有 localStorage 设置兼容。

## 验证

- 提取并执行内联 JavaScript 的语法检查。
- 本地 HTTP 服务加载页面，检查控制台错误。
- 桌面尺寸重点验证首页、选队页和比赛 HUD；再用窄屏检查无横向溢出、按钮可点和文字不重叠。
- 手动验证语言切换、球队选择、开始比赛、任务生成与任务完成路径。
